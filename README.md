# 💱 Currency Converter

A simple and responsive Currency Converter built using HTML, CSS, and JavaScript.

## 🚀 Features

- Convert between different currencies
- Fetches exchange rates using an API
- Dynamic currency dropdowns
- Automatically updates currency flags
- User-friendly interface
- Supports multiple currencies

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Currency API
- Flags API

⚙️ How It Works
1. Enter the amount you want to convert.
2. Select the currency you are converting from.
3. Select the currency you want to convert to.
4. Click Get Exchange Rate.
5. The application fetches the latest exchange rate and displays the converted amount.
🌐 API Used
Exchange rates are fetched using:
- Currency API
- Flags API
